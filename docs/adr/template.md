# ADR Template

Use this template for new Architecture Decision Records. Copy it to
`NNNN-<short-title>.md` (NNNN = sequential number, e.g. `0002-...`), fill in
every section, and keep the record immutable: supersede an old decision with a
new ADR that links to it instead of editing the old one.
